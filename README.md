## 🤔 Why Apex Academics?

Every student knows the struggle — you want to learn something new but:
- Googling gives you 50 sketchy websites
- Reddit threads are outdated
- Paid courses are expensive
- Free ones are buried under ads

**Apex Academics** solves this. One place, verified free, always updated — built by students, for students.

> 💬 *"We built this in our first year of BCA because we couldn't find a simple, fast place to discover free resources. So we made one."*
> — **Apex Academics Team**, BCA Science Year 1

## ✨ Features

- ⚡ **Instant Search** — results appear as you type, no page reload
- 🏷️ **Smart Filters** — filter by Subject, Level, Type, and Language
- ✅ **Verified Free** — every link is manually checked, no paywalls
- 🇮🇳 **India-First** — includes Hindi & regional language resources
- 📱 **Mobile Friendly** — works great on your phone
- 🤝 **Community Driven** — anyone can add resources via Pull Request
- 🚀 **No Backend** — pure HTML/CSS/JS, loads instantly
- 🌙 **Dark Mode** — easy on the eyes during late-night study sessions
