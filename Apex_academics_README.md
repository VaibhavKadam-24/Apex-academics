## 🤔 Why Apex Academics?

Every student knows the struggle — you want to learn something new but:
- Googling gives you 50 sketchy websites
- Reddit threads are outdated
- Paid courses are expensive
- Free ones are buried under ads

**Apex Academics** solves this. One place, verified free, always updated — built by students, for students.

> 💬 *"I built this in my first year of BCA because I couldn't find a simple, fast place to discover free resources. So I made one."*
> — vaibhav kadam, BCA Year 1

---

## ✨ Features

- ⚡ **Instant Search** — results appear as you type, no page reload
- 🏷️ **Smart Filters** — filter by Subject, Level, Type, and Language
- ✅ **Verified Free** — every link is manually checked, no paywalls
- 🇮🇳 **India-First** — includes Hindi & regional language resources
- 📱 **Mobile Friendly** — works great on your phone
- 🤝 **Community Driven** — anyone can add resources via Pull Request
- 🚀 **No Backend** — pure HTML/CSS/JS, loads instantly
- 🌙 **Dark Mode** — easy on the eyes during late-night study sessions

## 📋 Resource Format

Each resource in the JSON files follows this simple format:

```json
{
  "title": "Python Crash Course",
  "author": "Eric Matthes",
  "category": "ebook",
  "subject": "Python",
  "level": "Beginner",
  "language": "English",
  "link": "https://example.com/python-crash-course",
  "source": "Archive.org",
  "verified": true,
  "tags": ["programming", "python", "bca", "btech"]
}
```

## 🤝 How to Contribute

Contributions are what make this project grow! Here's how you can help:

### ➕ Add a Free Resource (Easiest way to contribute)

1. **Fork** this repository (click the Fork button top-right)
2. Edit the relevant JSON file inside `/data/`
3. Add your resource following the format above
4. Submit a **Pull Request** with a short description

> 📌 Please make sure the resource is **actually free** before adding it!

### 🐛 Found a Broken Link?
[Open an Issue](https://github.com/YOUR_USERNAME/apex-academics/issues/new) and paste the broken link. We'll fix it fast.

### 💡 Have a Feature Idea?
Start a [Discussion](https://github.com/YOUR_USERNAME/apex-academics/discussions) or open an issue tagged `enhancement`.

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.
